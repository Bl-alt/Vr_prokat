# VR-прокат — Telegram-бот для записи

Бот для записи на прокат Oculus Quest 2 / Quest 3: выбор консоли, тарифа, даты и времени
с проверкой занятости, отмена записи, уведомления администратору.

## Запуск

Требуется Python 3.11+.

```bash
python3 -m venv .venv
source .venv/bin/activate          # Windows: .venv\Scripts\activate
pip install -r requirements.txt

cp .env.example .env               # и заполните BOT_TOKEN, ADMIN_CHAT_ID
python main.py
```

Переменные `.env`:

| Переменная | Описание |
|---|---|
| `BOT_TOKEN` | токен от @BotFather (обязательно) |
| `ADMIN_CHAT_ID` | id чата/пользователя для уведомлений о бронях и отменах. Администратор должен хотя бы раз написать боту `/start` (для группы — добавить бота в неё) |
| `TIMEZONE` | часовой пояс пункта проката, по умолчанию `Europe/Moscow` |
| `QUEST2_UNITS`, `QUEST3_UNITS` | сколько единиц каждой модели в наличии (по умолчанию 1) |
| `DB_PATH` | путь к файлу SQLite (по умолчанию `bookings.db`) |

## Тесты

```bash
pytest
```

Покрыты: границы рабочего дня, скрытие прошедшего времени, окно записи 14 дней, перенос возврата
на 8:30 следующего дня, пересечения броней, лимит по количеству устройств, цены, валидация
имени/телефона, атомарное сохранение брони в БД (в т.ч. одновременные попытки) и отмена.

## Структура

```
config.py            настройки из .env и бизнес-параметры (часы работы, тарифы, кол-во консолей)
content.py           тексты «Возможности и игры» и «Условия проката» — правьте здесь
main.py              точка входа
db/database.py       SQLite (aiosqlite): таблица bookings, атомарное создание брони, отмена
services/schedule.py расчёт времени возврата, свободных слотов и дат (чистые функции)
services/pricing.py  цены и названия тарифов
services/validators.py  проверка имени и телефона
services/formatting.py  форматирование дат и сводки брони
handlers/            common (меню, /start), booking (FSM записи), cancel (отмена), fallback
keyboards/           inline- и reply-клавиатуры, callback_data
tests/               pytest
```

## Правила расписания

- Выдача — с 8:30 до 17:30 с шагом 30 минут (выдача и возврат возможны только с 8:30 до 18:00).
- Почасовая аренда, которая заканчивается позже 18:00, возвращается на следующий день к 8:30 —
  до этого момента устройство занято. Аренда, заканчивающаяся ровно в 18:00, возвращается в тот же день.
- Сутки / неделя — возврат в то же время через 1, 2 или 7 суток.
- Брони одной модели не могут одновременно превышать число единиц (`QUEST*_UNITS`).
- При нажатии «✅ Согласен» доступность проверяется повторно внутри транзакции
  (`BEGIN IMMEDIATE`), поэтому два клиента не займут одно устройство.
- Время в БД хранится в ISO 8601 в UTC со смещением (`+00:00`), показывается в `TIMEZONE`.
- Отменённые брони не удаляются — у них `status = 'cancelled'`.

## Замечания

- Состояние диалога (FSM) хранится в памяти: после перезапуска бота незавершённая запись
  сбрасывается (пользователь увидит подсказку нажать /start). Сами брони хранятся в SQLite.
  Для нескольких экземпляров бота замените `MemoryStorage` на `RedisStorage`.
- Принимаются российские мобильные номера (+79…), они приводятся к виду `+7XXXXXXXXXX`.
